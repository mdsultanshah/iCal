# Glossary

Words used in the booking calendar prototype.

- **Service**: what you book, with a fixed length.
- **Time**: a start time that is free for the chosen service. The booking rules call this a slot. Customers do not see the word slot.
- **Booking**: a confirmed time with a name and an email.
- **Booking reference**: the short code shown after confirming.
- **Cancel link**: the link that cancels one booking.
- **Reschedule link**: the link that moves one booking to a new time.
